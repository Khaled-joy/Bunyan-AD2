Build تراثنا / Turathuna — "Our Heritage", a bilingual (Arabic/English) educational mini-game about UAE heritage, national identity, and Islamic knowledge, for ages 6–17.

Stack: React + Vite + Tailwind CSS + Framer Motion. Single-page app, no backend, no database. Progress, stars, and badges live in React state for the session. Sound via Howler.js. Full RTL support — when Arabic is active, set dir="rtl" and mirror all layouts, progress bars, and drag tracks.

1. Brand palette — locked to the logo

Create src/theme.js with this token set. Every colour in the app must come from here. No hardcoded colours anywhere else in the codebase.

js
export const brand = {
  primary:   '#______', // main logo colour — headers, primary buttons, timer ring
  secondary: '#______', // second logo colour — panels, level cards, borders
  accent:    '#______', // brightest logo colour — stars, rewards, celebration only
  bgLight:   '#______', // pale tint of primary — page background
  bgDeep:    '#______', // dark tint of primary — body text, overlays, footer
  correct:   '#______', // success state, from the logo family
  incorrect: '#______', // soft, desaturated warm tone — never harsh red
};

Wire these into tailwind.config.js as custom colours so they can be used as bg-primary, text-bgDeep, border-accent, etc.

Application rules:

Page background: bgLight, with an Al Sadu weave geometric pattern (repeating zigzag/diamond motif) overlaid at 6% opacity in primary.
Question cards: near-white, 3px secondary border, soft shadow. Hover → border shifts to accent.
Timer ring: primary → accent at 40% remaining → incorrect at 15%.
Stars and badges: always accent. Nothing else uses accent, so reward moments stay visually special.
Correct answer: card fills correct at 15% opacity, solid correct border, particle burst in accent, soft ding.
Wrong answer: gentle shake, 2px incorrect border only. No fill, no flash, no buzzer. Keep it kind for young children.
Level cards: Level 1 secondary, Level 2 primary, Level 3 bgDeep — same family, deepening with difficulty.
Locked levels: bgDeep at 30% opacity with a lock icon in bgLight.
Icons: two-tone only — bgDeep line work, accent fills. No per-icon custom colours.
UAE flag colours (green, red, white, black) appear only when the flag itself is depicted. They are content, not theme.
Every text/background pair must pass WCAG AA (4.5:1). If a logo colour is too light for body text, use bgDeep for text and keep the light colour for fills and borders.
2. Look & feel
Tone: warm modern-Emirati. A children's museum in Abu Dhabi, not a cartoon and not a corporate dashboard.
Typography: Arabic — Tajawal or Cairo, bold. English — Poppins. Large, rounded, high contrast, generous line height.
Icon set needed: falcon, camel, ghaf tree, Arabian oryx, dhow boat, pearl, dallah coffee pot, date palm, kandura, abaya, mosque, crescent moon, Kaaba, prayer mat, Qur'an, lantern, Burj Khalifa, Hope Probe, oil derrick, Al Sadu loom, henna hand, luqaimat, harees bowl, majlis cushion, falconry glove, UAE flag, seven emirate crests.
Motion: cards flip and bounce in on load. Answers respond instantly. Transitions under 300ms.
Timer: a circular ring drains clockwise around the question card. Soft tick under 5 seconds. On timeout the card dims, the correct answer is revealed for 2 seconds, then auto-advance.
Progress: a dhow boat silhouette in primary sails across a secondary line at the top of the screen as the player advances, wake in accent.
Rewards: 1–3 gold stars per mini-game based on accuracy plus time remaining. Completing a level unlocks a collectible heritage badge — Level 1 the pearl, Level 2 the falcon, Level 3 the ghaf tree — displayed on a trophy shelf on the home screen.
3. Screens
Home — تراثنا in large calligraphic-style Arabic type, EN/AR toggle in the corner, "ابدأ / Start" button, trophy shelf below.
Level select — three cards; Levels 2 and 3 locked until the previous is complete. Each shows level name, age hint, stars earned.
Mini-game select — four tiles per level, each with its format icon.
Gameplay — question card centred, timer ring, score top corner, dhow progress bar top.
Results — stars, a "تعلمت اليوم / I learned today" recap of every fact from the round, then Retry / Next.
4. Mini-game formats
MCQ — four tappable icon+text cards.
True/False — large ✓ and ✗ buttons (Level 1 only).
Matching — two columns; tap left then right to link. Correct pairs join with a gold Al Sadu thread in accent.
Ordering — drag tiles into the correct sequence along a horizontal track.
Sorting — drag items into two or three labelled baskets.
5. Timing
Level	MCQ / True-False	Matching / Ordering / Sorting
1	25s	60s
2	18s	45s
3	12s	35s

Include a parent/teacher toggle in the corner that disables all timers for classroom use.

7. Learning-first rules
After every question, show a "هل تعلم؟ / Did you know?" card for 3 seconds. Write one fact for each question. Example: "The ghaf tree survives with almost no rain — it became the UAE's national tree in 2008."
Never display a wrong-answer count to the child. Show only stars earned and facts learned.
End every level with the "تعلمت اليوم / I learned today" scroll of all facts encountered, so the round closes on knowledge rather than score.
