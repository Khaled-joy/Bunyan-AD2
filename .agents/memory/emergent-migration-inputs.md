---
name: Emergent migration inputs
description: What is required before importing an Emergent mini-game into Bunayn AD.
---

An Emergent snapshot can document the product blueprint without containing the playable game source or assets. A real migration requires the game’s exported ZIP/repository and any referenced assets.

**Why:** The supplied snapshot described the game suite and unfinished status, but did not include runnable source files.

**How to apply:** Keep imported games clearly marked as pending until the actual source export is provided; use the platform’s game-entry contract when adding each new mini-game.
